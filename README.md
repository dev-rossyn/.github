## 🔧 What We Use

### The Main Stuff
- **Language:** Kotlin is our go-to (Java when needed)
- **UI:** Jetpack Compose and XML layouts
- **Architecture:** MVVM + Clean Architecture - keeps things organized
- **Dependency Injection:** Hilt Dagger mostly, sometimes Koin
- **Async:** Coroutines and Flow for smooth operations
- **Database:** Room for local storage
- **Networking:** Retrofit + OkHttp for API calls

### Dev Tools
- Android Studio (of course)
- Git and GitHub for version control
- Gradle for builds
- GitHub Actions for CI/CD
- JUnit, Espresso for testing
- Firebase for analytics and crash reporting
