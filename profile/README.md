# 🚀 Welcome to Sumino Apps!

Hey! We're Sumino Apps, an Android dev team from India who genuinely love building apps that work great and look even better. Our focus is simple: make useful stuff that people actually want to use.

**Wanna check out what we've made?** [Head over to Play Store](https://play.google.com/store/apps/dev?id=8710921208482901698) 📱

---

## 💡 What Do We Build?

Honestly, it depends on what's needed. But here's what we specialize in:

- **Apps that connect to APIs** – We build apps that talk to backend servers and keep data synced properly
- **GPS & Location stuff** – Maps, tracking, location-based features - we know how to handle all that
- **Useful daily tools** – Simple apps that solve real problems people face
- **Fast & efficient** – We hate bloated apps. Everything we make runs smooth, even on older phones
- **Privacy-first** – Your data matters, so we take security and privacy seriously

---

## 🛠️ What We Work With

The tools and tech we use every day:

**Languages & Frameworks:** Kotlin • Jetpack Compose • MVVM • Clean Architecture  
**Backend stuff:** Retrofit • OkHttp • REST APIs • Firebase  
**Data & Storage:** Room Database • DataStore • SQLite  
**UI & Design:** Material Design 3 • Modern Android Components  
**Testing:** JUnit • Espresso • Unit Tests • Integration Tests  
**Tools:** Android Studio • Git • Gradle  

---

## 🎯 How We Actually Work

Our process is pretty straightforward, nothing fancy:

1. **Planning** – We figure out what we're building
2. **Design** – We plan it out properly before diving into code
3. **Development** – We write clean Kotlin code with best practices
4. **Testing** – We test everything thoroughly
5. **Optimization** – We make sure it's fast and doesn't drain battery
6. **Release** – We gradually roll out on Play Store
7. **Maintenance** – We keep improving based on feedback
